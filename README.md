# CPTS 350 — Design and Analysis of Algorithms

Washington State University

## Course Overview

CPTS 350 focuses on the design and analysis of algorithms, including computational complexity, algorithmic design techniques, graph algorithms, and computational intractability.

**Credits:** 3
**Instructor:** Zhe Dang
**Textbook:** *Introduction to Algorithms*, 4th Edition — Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, and Clifford Stein

## Topics

* Algorithm fundamentals
* Worst-case and average-case complexity
* Comparison-based sorting and lower bounds
* QuickSelect
* MergeInsert
* Divide and conquer

  * Karatsuba algorithm
  * Closest pair problem
* Dynamic programming

  * Longest Common Subsequence (LCS)
  * Generalized LCS
  * Applications in bioinformatics
* Greedy algorithms

  * Huffman coding
* Amortized analysis

  * Aggregate method
  * Accounting method
  * Potential method
* Graph algorithms

  * DFS
  * BFS
  * Topological sorting
  * Minimum spanning trees
  * Shortest paths
  * Strongly connected components
* Symbolic graph search
* Number-theoretic algorithms

  * RSA
  * Security protocols
* NP-completeness

  * Many-one reductions
  * SAT
  * 3SAT
* Automata-theoretic algorithms

## Learning Goals

By completing this course, I aim to develop the ability to:

* Analyze algorithm complexity using recurrence relations and growth-rate estimation.
* Design algorithms using fundamental algorithmic techniques.
* Work with symbolic algorithms and large data structures.
* Express algorithmic ideas using both natural language and mathematical notation.
