# CPTS 422 — Software Engineering Principles II

**Washington State University**
**Instructor:** Dr. Balasubramanian "Subu" Kandaswamy
**Credits:** 3

## Course Overview

CPTS 422 focuses on the fundamentals of **software testing**, verification, and validation. The course covers testing at multiple levels and for different objectives, including functionality, performance, and security. It also explores testing methodologies, techniques, tools, and measures for evaluating the quality of software and its tests.

The course includes a semester-long team project involving the development of an **enterprise Java web application using Spring MVC**, where testing techniques from the course are applied to a larger software system.

## Topics

* Software testing fundamentals
* Testing theory and methodology
* Boundary value testing
* Equivalence class testing
* Decision table testing
* Path testing
* Branch coverage
* JUnit 5
* Integration testing
* Mockito
* Data flow testing
* Mutation testing
* System testing
* Selenium
* Performance testing and profiling
* Property-based testing
