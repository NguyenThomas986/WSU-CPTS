# CPTS 223 — Advanced Data Structures in C++

Washington State University

## Course Overview

CPTS 223 focuses on the design, implementation, and analysis of advanced data structures and algorithms in C++. The course builds upon foundational data structures from CPTS 122 and covers algorithm efficiency, the Standard Template Library, empirical performance evaluation, and parallel programming.

**Credits:** 3
**Instructor:** Subu Kandaswamy
**Textbook:** *Data Structures and Algorithm Analysis in C++*, 4th Edition — Mark Allen Weiss

## Topics

* Algorithm design techniques
* Asymptotic notation and complexity analysis
* Binary Search Trees (BST)
* AVL Trees
* B-Trees and B+ Trees
* Hash Tables
* Heaps

  * Binary heaps
  * Binomial heaps
* Disjoint Sets
* Sorting algorithms
* Graphs and graph algorithms
* Standard Template Library (STL)
* Empirical performance evaluation
* Parallel programming
* Multithreading in C++
* C++ programming and debugging
* Version control with Git and GitHub
* C++ technical interview problems

## Learning Goals

By completing this course, I aim to develop the ability to:

* Design, implement, and test programs using modern C++ tools and techniques.
* Analyze and compare advanced data structures and algorithms.
* Evaluate algorithm efficiency using asymptotic analysis and empirical performance.
* Design efficient algorithms to solve problems.
* Apply data structures such as trees, hash tables, heaps, disjoint sets, and graphs.
* Use Git and GitHub effectively for version control.
* Develop structured and maintainable C++ programs in a Linux environment.
* Apply parallel programming and multithreading concepts in C++.
* Solve C++ data structures and algorithm problems commonly encountered in technical interviews.
